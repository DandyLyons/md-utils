Installation

Current native source builds require Swift 6.3 or later with a matching SDK. macOS is the primary development platform; Ubuntu 24.04 x86_64 and ARM64 have native CI coverage. See the platform and build guide for prerequisites and distribution status.

macOS with Mint 
mint install DandyLyons/md-utils
mint run DandyLyons/md-utils --help

Mint builds the Swift executable package from the tagged GitHub source.

From Source 
git clone https://github.com/DandyLyons/md-utils.git
cd md-utils/
swift build -c release --product md-utils
swift build -c release --show-bin-path

Run the CLI from the reported directory. Preserve SwiftPM resource bundles beside the executable when installing elsewhere. Build the native server separately with swift build -c release --product md-utils-server.

Linux ARM64 preview

The Ubuntu 24.04 ARM64 CLI archive is verified without a Swift toolchain. The first planned prerelease, 0.3.0-linux.1, awaits tagged publication. Follow the archive installation guide for runtime packages, checksums, resources, and corresponding source. Server archives and other Linux binary targets are not yet available.

WebAssembly support is separate: MarkdownUtilitiesCore builds with the Swift 6.3.1 WASI SDK, but has no packaged release or stable JavaScript interface.

Agent Skill 
npx skills add https://github.com/DandyLyons/md-utils --skill markdown-utilities

Quick Start


md-utils toc README.md
md-utils fm dump document.md
md-utils extract --name "Installation" README.md
md-utils links check --vault ~/notes/ docs/
md-utils schema init books --path "Books/**/*.md" --tag Book

Hosted Schema

The default configuration schema is version 0.2.0. Configuration schema versions evolve independently of CLI releases; configuration 0.3.0 remains opt-in.

The moving /schemas/latest/md-utils.schema.json alias and /md-utils.schema.json root compatibility alias currently point to 0.2.0. Existing versioned schema URLs remain available.

{
  "$schema": "https://dandylyons.github.io/md-utils/schemas/0.2.0/md-utils.schema.json",
  "configVersion": "0.2.0",
  "schemaDirectory": ".md-utils/schemas/",
  "rules": []
}
