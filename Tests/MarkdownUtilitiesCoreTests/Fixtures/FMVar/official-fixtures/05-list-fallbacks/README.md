# List empty states

Operation: synchronize every reference in `before.md` once, producing `after.md`.

In order: two zero-result fallbacks and two null-result fallbacks. Each replaces the entire list cache with escaped text, without a list wrapper or item (Sections 2.2 and 3.7).
